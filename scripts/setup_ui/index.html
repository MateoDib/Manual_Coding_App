APPLICATION DE CODAGE · V3

Votre espace de codage

Quelques réglages, un fichier d’interviews, et vous pouvez commencer.

Chargement des réglages…

1

Qui participe au codage ?

Les codages de chaque personne restent séparés.

Séparez les noms par une virgule. Réutilisez exactement le même nom lors des prochaines sessions. Modifier un nom crée un autre codeur ; les anciens codages restent conservés.
2

Ajouter les interviews

Le fichier reste sur votre ordinateur. Il n’est envoyé à aucun service externe.

Un fichier d’interviews est déjà en place. Il sera conservé si vous n’en choisissez pas un autre.

Le dossier sera créé à l’enregistrement. Vous pourrez y placer un fichier nommé interviews.csv, ou revenir dans Configurer.command.

Quel format de fichier utiliser ?

Colonnes : PID, pair_id_interview, pair_order_interview, question, response. interview_id est facultatif. Séparateur : virgule. Aucune colonne de phase.

Emplacement des interviews

3

Assistance IA facultatif

Une recommandation est demandée uniquement lorsque vous cliquez sur son bouton dans l’application.

Chaque demande transmet à OpenAI les textes nécessaires au codage. Aucun identifiant de participant n’est transmis par l’application.

En cliquant sur Enregistrer, vous autorisez son enregistrement dans le fichier privé .env de cette application. Elle n’est jamais affichée ensuite.
Gardez le modèle proposé si vous ne souhaitez pas le changer.
Réglages avancés

Les ports doivent être différents. Les réglages prennent effet au prochain lancement.

Tout reste dans le dossier de l’application

  • data/interviews/ : le fichier source ;
  • outputs/database/ : une base de référence, avec toutes les révisions ;
  • outputs/coding/nom_du_codeur/ : les exports de codage à la demande ;
  • outputs/analyses_dags/nom_du_codeur/ : les descriptifs et l’évolution des DAGs.

Le fichier .env, les interviews et les résultats sont exclus de Git. Le dossier de code reste publiable.

Vous pourrez modifier ces réglages à tout moment.

Votre configuration est enregistrée

Pour coder, double-cliquez sur Lancer_Codage.command. Pour les analyses, utilisez Lancer_Statistiques.command. Si l’application était ouverte, fermez son Terminal avec Ctrl+C, puis relancez-la.
